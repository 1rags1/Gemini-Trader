Gemini Trend Guard

Paper-trading bot

This GitHub Pages site is only a project landing page. The live monitor, Gemini confirmations, and paper fills run on your machine — they are not published here, because they need your .env keys and the local runner.

On the computer that is running the bot:

  1. Keep the runner going: python -m core.strategy_runner
  2. Start the desk: python -m core.dashboard
  3. Open http://127.0.0.1:8050
